# User Guide

## Navigation

The website has a consistent navigation bar at the top with the following links:
- **Home** - Returns to homepage
- **Destinations** - Browse all destinations
- **Hotels** - Browse hotels
- **Flights** - Browse flights
- **Activities** - Browse activities
- **Transfers** - Browse transfers
- **Login/Register** - Authentication (when not logged in)
- **My Bookings** - View your bookings (when logged in)
- **Profile** - View/edit your profile (when logged in)
- **Logout** - Log out (when logged in)

## Browsing Destinations

1. Click on **Destinations** in the navigation
2. Use filters to narrow down results:
   - **Country** - Filter by country
   - **Search** - Search by name or description
3. Click on a destination card to view details
4. On the destination details page:
   - View destination information and photos
   - See hotels and activities in that destination
   - Submit an inquiry form

## Making Bookings

### Booking a Hotel
1. Browse hotels using the **Hotels** page
2. Use filters: city, country, price range, rating
3. Click on a hotel to view details
4. Fill in booking form:
   - Check-in date
   - Check-out date
   - Number of nights
5. Click **Book Now**
6. If not logged in, you'll be redirected to login page

### Booking a Flight
1. Browse flights using the **Flights** page
2. Use filters: origin, destination, date
3. Click on a flight to view details
4. Click **Book Now** on the flight details page

### Booking an Activity
1. Browse activities using the **Activities** page
2. Use filters: city, date
3. Click on an activity to view details
4. Click **Book Now** on the activity details page

### Booking a Transfer
1. Browse transfers using the **Transfers** page
2. Use filters: origin, destination, date
3. Click on a transfer to view details
4. Click **Book Now** on the transfer details page

## User Account Management

### Registration
1. Click **Register** in the navigation
2. Fill in the form:
   - Full Name
   - Email
   - Password (minimum 6 characters)
   - Role (Customer, Travel Agency, or Hotel Owner)
3. Click **Register**
4. You'll be automatically logged in

### Login
1. Click **Login** in the navigation
2. Enter your email and password
3. Click **Login**
4. You'll be redirected to the homepage

### Viewing Bookings
1. Click **My Bookings** in the navigation
2. View all your bookings with status
3. Cancel bookings if needed (only confirmed bookings can be cancelled)

### Profile Management
1. Click **Profile** in the navigation
2. View and edit your profile information:
   - Full Name
   - Phone
   - Address
3. Click **Update Profile** to save changes

## Features

### Search
- Use the search functionality to find hotels, flights, activities, transfers, and destinations
- Search is available on the homepage and listing pages

### Filters
- All listing pages have filters to help you find what you're looking for
- Filters include: location, date, price range, rating

### Responsive Design
- The website works on desktop, tablet, and mobile devices
- All pages are optimized for different screen sizes
